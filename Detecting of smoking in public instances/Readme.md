# 🚭 Smoking Detection in Public Places

An AI-powered system to **detect smoking activities in public spaces** using computer vision and deep learning.  
This project aims to support **public safety, law enforcement, and smart city initiatives** by automatically identifying smoking instances from images or video streams.

---

## 📌 Problem Statement
Smoking in public places is prohibited in many regions due to health and safety concerns. Manual monitoring is inefficient and error-prone.  
This project provides an **automated solution** to detect smoking behavior using AI-based visual analysis.

---

## 🎯 Objectives
- Detect smoking activities in images and video feeds
- Assist authorities in enforcing public smoking regulations
- Enable real-time or batch analysis
- Reduce manual monitoring effort
- Support Smart City surveillance systems

---

## 🧠 Approach
The system uses **computer vision and deep learning models** to:
- Detect humans in the scene
- Identify smoking-related objects (cigarettes, smoke)
- Analyze contextual cues (hand-to-mouth gesture, smoke presence)
- Classify the activity as **Smoking / Non-Smoking**

---

## 🛠️ Tech Stack
- **Programming Language:** Python
- **Libraries & Frameworks:**
  - OpenCV
  - NumPy
  - TensorFlow / PyTorch
  - YOLO / CNN-based models
- **Deployment:** Local machine / Cloud (optional)
- **Data Format:** Images / Videos / CCTV feeds
